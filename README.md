# SE68 Hub

เว็บศูนย์กลางประกาศและติดตามงานสำหรับนิสิตวิศวกรรมซอฟต์แวร์ รุ่น 68

## Stack

- HTML5 + CSS3 + TypeScript
- Vite สำหรับ Development และ Build
- Supabase Auth, PostgreSQL และ Realtime

## เริ่มต้น

1. คัดลอก `.env.example` เป็น `.env.local`
2. ใส่ Supabase URL และ anon key
3. รัน `npm install`
4. รัน `npm run dev`

แก้ source ใน `src/` เท่านั้น ส่วน `dist/` เป็นผลลัพธ์จาก `npm run build`
